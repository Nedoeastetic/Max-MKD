# 🚀 Быстрый старт бота с реальным AI API

## Шаг 1: Вставьте токен

Откройте `bot/.env` и замените `ВСТАВЬТЕ_ТОКЕН_СЮДА` на ваш токен от @MasterBot:

```env
MAX_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ML_API_URL=https://v3258578.hosted-by-vdsina.ru
```

## Шаг 2: Установите зависимости

```bash
cd bot
npm install
```

## Шаг 3: Проверьте ML API (опционально)

```bash
npm run test:api
```

Найдите вашего бота в MAX и отправьте:

```

```

Ожидаемый ответ:
```

📋 Категория: Водоснабжение
📍 Подкатегория: Протечка трубы
⚡ Срочность: Высокий
🎯 Уверенность AI: 94%
```

### Тест 2: Фото
Отправьте любое фото. Бот должен:
- Если это проблема → классифицировать и задать уточнения
- Если нерелевантно (кот, еда) → ответить "Не удалось обнаружить проблему"

### Тест 3: Команды

```
/health
```

## 🔧 Что происходит под капотом

1. **Пользователь отправляет сообщение** → бот получает событие через Long Polling
2. **Бот скачивает фото** (если есть) из MAX
3. **Отправляет в ML API:**
   - Текст → `POST /api/text/analyze`
   - Фото → `POST /api/vision/analyze` (multipart/form-data)
4. **Fusion Engine объединяет результаты:**
   - Text + Vision → высокая уверенность
   - Только Text → использует text classifier
   - Только Vision → задаёт вопросы для описания
   - Конфликт → запрашивает уточнение
5. **Показывает карточку заявки** с категорией, срочностью, уверенностью
6. **Пользователь подтверждает** → заявка создаётся в хранилище

---

**Если что-то не работает:**
1. Проверьте токен в `.env`
2. Проверьте доступность ML API: `npm run test:api`
3. Проверьте логи бота в консоли
4. Убедитесь, что бот верифицирован в MAX

**Полезные команды:**
- `/health` — проверить статус ML сервиса
- `/status` — посмотреть ваши заявки
- `/start` — начать заново
